### What is StoryFlow?

StoryFlow Editor is a visual node-based tool for creating interactive stories, branching dialogues, and narrative systems. Build your story logic with 160+ node types, then export and run it in your game engine of choice.

- Visual node graph for dialogue, branching, and logic
- Variables, arrays, characters, audio, and images
- Live sync between editor and game engine during development
- Export to Unity, Godot, or Unreal Engine
